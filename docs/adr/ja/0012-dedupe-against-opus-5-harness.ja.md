# 0012: fable-coding を Opus 5 の Claude Code ハーネスと重複排除する

(English: [0012-dedupe-against-opus-5-harness.md](../en/0012-dedupe-against-opus-5-harness.md))

## 背景

ユーザーが常用モデルを Claude Opus 5 に移し、それに合わせた最適化を求めた(2026-07-26)。`fable-coding` は Fable 5 を使っていた時期に組み上げたもので、その多くは当時のハーネスが述べていなかった規律を*補う*ためのものだった。Opus 5 の Claude Code システムプロンプトは、それらの規則のいくつかを自ら述べており、一部は逐語で一致する — セクション0 の「行動に足る情報が揃ったら行動する」の段落(ADR 0003 で Anthropic の Fable 5 プロンプティングガイドから取り込んだもの)は、ハーネスに一字一句そのまま存在する。

指示の重複は無料ではない。スキルの文脈予算を消費するうえ、`prompting-fable-5` 自身が Anthropic の指針として「旧モデル向けに書かれたスキルは過剰に規範的で出力を劣化させることが多い — 書き直す前にまず削ってみよ」を記録している。

## 決定

`skills/fable-coding/SKILL.md` から5項目を削除または圧縮し、`SKILL.ja.md` を追随させた:

- §0 行動に足る情報が揃ったら行動する / 確定済みの事実を再導出しない — ハーネスに逐語で存在。
- §1 依存のない検索は並列に走らせる — ハーネスが述べている。
- §3 周囲のコードの命名・イディオムに合わせる — ハーネスが述べている。
- §5 結果を忠実に報告する — 重複しない唯一の節、すなわち飛ばしたステップは*飛ばした理由まで付けて*名指す、だけに圧縮。
- §7 過剰に謝らずミスを認める — ハーネスの Corrections 節が述べている。

112行から107行へ。バージョン 2.5.0。

意図的に残したもの: セクション3の ponytail ラダー。ponytail プラグインの SessionStart 注入と重複するが、あちらは独立にインストールされるものであり、`fable-coding` はそれ無しで自己完結する必要がある。スキル名・プラグイン名も現状維持(ADR 0007)。

## 検証

挙動ではなくテキストによる検証: 削除した各行は、削除前にこのセッションの Opus 5 Claude Code システムプロンプトと突き合わせて一致を確認し、英語版と和訳の diff を比較して両ファイルが同じ5箇所で変更されたことを確認した。ADR 0010 / 0011 と異なり、ネストした `claude -p` による RED/GREEN 実行は行っていない — この変更は挙動の追加ではなく冗長性の除去であり、検証すべき命題が「変わらない挙動が変わらなかったこと」になるため、その実行では綺麗に示せない。

## 却下した代替案

- **アンチパターン一覧も削除する**(15項目・17行、いずれもセクション0〜9の言い換えで、ガイドの「brief beats enumerated」に反する): ユーザーに提示したが、保守的な削除が選ばれた。
- **何も変えない** — 重複を許容することになるが、そのコストはコーディングタスクのたびに支払われる。
- **Opus 5 向けにスキルを書き直す** — 内容はそもそも Fable 固有ではなく、固有だったのは冗長性だけなので、書き直しは空回りになる。

## 帰結

- スキルはハーネスが持たないものだけを担うようになり、残るのはユーザー固有の部分になる: 日本語での報告、DB 操作の事前報告、ADR の義務、armadillo 7則、スタックノート。
- 既知の上限: この削除は Opus 5 の Claude Code ハーネスに合わせて較正されている。これらの規則を述べないハーネス — 旧モデル、SDK エージェント、素の API 統合 — では、削除した行を供給するものが無くなる。復元はこの ADR と v2.4.0 の git 履歴から可能。
- `prompting-fable-5` は変更していない: Fable 5 を「プロンプトする側」の文書であり、どのモデルが読むかに左右されない。「refusal 時は Opus 4.8 にフォールバック」の記述は Opus 5 が出た今では古い可能性があるが、この行は Anthropic のガイドの引用であり、このセッションで現行ガイドと突き合わせ直してはいない。
